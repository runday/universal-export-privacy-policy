Privacy Policy for Universal Export

Last updated: 2026-05-15

Overview

Universal Export is a Chrome extension designed to export AI chat conversations and web text as Markdown, PDF, or Word files, with an optional local knowledge base. We do not collect, store, or transmit your personal data to any server controlled by the developer.

Data Collection

Universal Export collects zero data. There is no analytics, no tracking, no telemetry, and no advertising in this extension. The developer does not operate any backend servers and has no means to receive your data.

Local Storage

All data created by the extension is stored exclusively on your device using Chrome's storage.local API and IndexedDB:

  • Knowledge Base entries — Your saved conversations, including titles, content, tags, categories, and metadata
  • Settings — Your preferences, LLM provider configuration, and GitHub sync settings
  • API Keys — Your LLM provider API keys and GitHub personal access tokens

This data never leaves your browser unless you explicitly choose to sync it (see GitHub Backup below).

AI Processing (Optional Feature)

When you enable AI enhancement features:

  • Selected chat content is sent directly from your browser to the LLM provider you configure (DeepSeek, OpenAI, Google Gemini, Alibaba Qwen, ByteDance Doubao, or a local Ollama instance)
  • The extension acts as a client only — it does not route traffic through any intermediate server
  • Content is only sent when you take an explicit action (export or save to knowledge base)
  • The extension never scans pages or reads conversations without your action
  • Your API key is stored locally and transmitted only to the provider's official API endpoint

You are responsible for complying with your chosen LLM provider's terms of service and privacy policy.

GitHub Backup (Optional Feature)

If you enable GitHub backup:

  • Your knowledge base data is pushed to a GitHub repository that you own and control
  • Your GitHub personal access token is stored locally on your device
  • You control the repository visibility (private recommended for sensitive content)

Permissions

The extension requests the following Chrome permissions:

PermissionPurpose
contextMenusAdd export options to the right-click menu
activeTabAccess the current tab to detect selected content
scriptingExecute export logic on the current page
downloadsSave exported files to your computer
storage / unlimitedStorageStore knowledge base entries and settings locally
alarmsSchedule periodic AI optimization tasks
<all_urls>Work on any AI chat website you visit (not limited to a preset list)
LLM provider hostsCall AI APIs directly from your browser

None of these permissions are used to collect, track, or transmit user data to the developer.

Third-Party Services

This extension integrates with third-party LLM API providers solely as a client. When you use AI features, your selected content is sent to the provider you configure. Please refer to their respective privacy policies:

  • DeepSeek Privacy Policy
  • OpenAI Privacy Policy
  • Google Gemini Privacy Policy
  • Alibaba Qwen Privacy Policy
  • ByteDance Doubao Privacy Policy

Children's Privacy

This extension is not directed at children under the age of 13. It does not knowingly collect personal information from children.
